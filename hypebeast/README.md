# HYPEBEAST portfolio draft

This is a separate homepage route built from the visual language of the main portfolio at `/`.

Open it at:

`http://127.0.0.1:4180/hypebeast/index.html`

The homepage intentionally reserves four Figma slots:

- `culture-research`: Xiaohongshu × Bilibili research case
- `visual-communication`: selected community or event visual case
- `campaign-treatment`: brand, media or partnership concept
- `profile-board`: personal approach and references

When the Figma draft is ready, replace each `.slot-frame` or `.profile-frame` with the relevant image, case text and link. The current contact details, resume link and LinkedIn link are retained from the original portfolio.

The first completed case is available at `vision-game.html`. It uses the Vision Game poster and medal assets copied from the working `VD` folder, with English case text based on the project notes provided for the HYPEBEAST application.
